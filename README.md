# Kanye Soundboard

A little 30-pad sampler for messing around with sounds from Kanye West's *Runaway* and *Stronger*.

## About this project

This is just a fun personal project. It isn't commercial, nothing is sold, and it has no bad intentions. It isn't meant to infringe anyone's copyright, and it doesn't distribute any music. The full songs and instrumentals are not included in this repo.

All songs, recordings and likenesses belong to their respective owners:

- *Runaway*: Kanye West feat. Pusha T, from *My Beautiful Dark Twisted Fantasy* (2010, Roc-A-Fella / Def Jam)
- *Stronger*: Kanye West, from *Graduation* (2007, Roc-A-Fella / Def Jam), sampling Daft Punk's *Harder, Better, Faster, Stronger*
- Clip idea inspired by the [Runaway Soundboard](https://runaway.haidrr.com/) by @candhforlife

**If you own any of this material and want something removed, please [open an issue](../../issues) and it will be taken down.**

## Running it

Double-click `start.command`, or run:

```sh
python3 server.py
```

Then open http://localhost:8765. Play the pads with your keyboard (`1`–`0`, `Q`–`P`, `A`–`;`) or by clicking or tapping them. Use **LOAD TRACK** to play along with your own copy of a song.
